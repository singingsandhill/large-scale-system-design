# experiments

실험에 쓰는 **실행 가능한 것들**을 두는 자리입니다.
부하 테스트 스크립트, 데이터 생성기, 측정 도구 설정 등.

실험의 **결과와 해석**은 여기가 아니라 문서에 남깁니다.

| 무엇 | 어디에 |
| --- | --- |
| 실행 스크립트, 시나리오 파일 | `experiments/<주제>/` (여기) |
| 가설 · 측정값 · 결론 | `docs/chapters/<chapter>/experiment.md` |
| Chapter와 무관한 짧은 실험 기록 | `docs/playground/` |

## 규칙

- 필요해지기 전에 미리 만들지 않습니다. 지금은 비어 있는 게 정상입니다.
- 디렉터리마다 README를 두고 **재현 방법**(필요한 도구, 실행 명령, 기본 파라미터)을 적습니다.
- 실행 결과물(로그, 리포트, 원시 측정값)은 커밋하지 않습니다.
  요약과 결론만 문서로 옮기세요. 원시 로그를 꼭 남겨야 한다면 `.gitignore`의 `*.log` 규칙을
  먼저 확인해야 합니다.
- 애플리케이션 코드에 실험용 코드를 섞지 않습니다.
