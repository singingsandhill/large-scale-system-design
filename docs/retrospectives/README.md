# Retrospectives

회차별 회고입니다. 스터디 진행 방식 자체를 고쳐 나가기 위한 기록입니다.

## 쓰는 법

`docs/retrospectives/<YYYY-MM-DD>.md` 파일로 남깁니다.

```markdown
# YYYY-MM-DD 회고

- 회차 / 다룬 Chapter / 참여자

## 잘된 것
## 아쉬운 것
## 다음에 바꿀 것 (한 가지만, 구체적으로)
## 미뤄 둔 것 · 다시 볼 것
```

"다음에 바꿀 것"은 한 번에 하나만 정합니다.
정했으면 [Rules](../study/rules.md)에 반영하고, 다음 회고에서 지켜졌는지 확인합니다.

기술적으로 배운 내용은 회고가 아니라 Chapter 문서(`notes/`, `defense.md`)에 남깁니다.
