# Playground

Chapter와 직접 이어지지 않는 자유 실험 기록입니다.

책 진도와 무관하게 궁금한 것이 생겼을 때 여기에 남깁니다.

- JVM · Spring 동작을 확인해 본 것
- 라이브러리 비교
- "이렇게 하면 어떻게 될까" 수준의 짧은 실험
- 실패했지만 배운 게 있는 시도

## 쓰는 법

`docs/playground/<주제>.md` 파일 하나로 시작합니다. 형식은 자유지만 최소한 이 정도는 남겨 주세요.

```markdown
# <주제>

- 작성자 / 날짜

## 궁금했던 것
## 해본 것 (재현 가능한 명령 포함)
## 결과
## 알게 된 것
```

실험이 Chapter 설계 판단에 영향을 줬다면
해당 Chapter의 `experiment.md`나 [ADR](../architecture/adr/README.md)로 옮기고,
여기서는 링크만 남깁니다.

실행 가능한 스크립트·코드는 문서가 아니라 저장소 루트의 `experiments/` 아래에 둡니다.
